# 🎲 3D 주사위 던지기 (Interactive 3D Physics Game)

Three.js 3D 렌더링 및 Cannon.js 3D 강체 물리 엔진, Web Audio API를 활용한 실감나는 물리 시뮬레이션 주사위 게임입니다. (참고: 기관총앱스 주사위 굴리기 스타일의 3D 물리 바운스 효과 구현)

## 🚀 주요 특징 (Key Features)

- **Real 3D Physics Engine**: Three.js와 Cannon.js 물리 엔진을 결합하여 주사위가 공중으로 솟구치고, 벽과 바닥, 주사위끼리 서로 부딪히며 구르는 실감나는 3D 물리 연출
- **자연스러운 감속 및 미세 레벨링**: 물리 엔진에 의한 점진적 감속과 수평 미세 보정(Y축 회전 유지)으로 인위적인 튐이나 휙 도는 현상 없이 부드러운 안착 실현
- **1개 ~ 최대 5개 주사위 조절**: 1개부터 최대 5개까지 버튼 클릭 및 키보드 화살표(←/→)로 즉시 주사위 개수 전환
- **편리한 던지기 조작 유지**: 기존의 [굴리기] 버튼 클릭 방식 유지 + 3D 아레나 화면 클릭/터치 + <kbd>Space</kbd>/<kbd>Enter</kbd> 키보드 단축키 지원
- **충돌 강도 연동 Web Audio 효과음**: 주사위끼리 부딪힐 때의 단단한 충돌음, 바닥과 벽에 떨어질 때의 타격음, 던질 때의 바람소리를 외부 음원 파일 없이 절차적으로 합성
- **모션 진행 중 `...` 표시 & 결과 발표 글로우 이펙트**: 굴리는 동안 `...` 애니메이션이 표시되며, 결과 발표 시 합계 박스에 부드러운 빛남 및 펄스 이펙트와 맑은 알림음 제공
- **교육용 클린 UI & 계산식 제공**: 사행성 요소를 배제하고 1개 모드 시 단일 결과, 2~5개 모드 시 개별 주사위 눈금 칩 및 `2 + 4 + 5 = 11` 계산식 실시간 표기
- **히스토리 기록 관리**: 최근 8회의 결과를 칩 형태로 저장 및 원클릭 초기화
- **3-Way 테마 시스템**: 시스템 설정 동기화 / 라이트 모드 / 다크 모드 전환 (LocalStorage 연동)

## 💻 실행 방법

1. 브라우저(Chrome, Edge, Safari 등)에서 `dice_index.html` 파일을 바로 엽니다.
2. [굴리기] 버튼을 누르거나 주사위 화면을 클릭하여 주사위를 굴립니다.
3. 상단 탭(🎲 1 ~ 🎲 5)을 눌러 주사위 개수를 1개부터 최대 5개까지 변경할 수 있습니다.
