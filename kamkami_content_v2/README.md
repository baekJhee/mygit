# 깜깜이 콘텐츠 v2

## 실행
`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행하세요.

## 폴더 구조
- `index.html` : 깜깜이/주목 시키기 화면과 설정 모달
- `css/style.css` : 전체 화면 레이아웃 및 스타일
- `js/app.js` : 탭 전환, 색상 선택, 문구·배경 모달, 소리 on/off
- `assets/` : 향후 이미지·음원 리소스 보관용

## 조작
- 상단 탭에서 깜깜이 / 주목 시키기 전환
- 깜깜이 모드: 하단 컬러 판에서 배경색 선택
- 주목 시키기 모드: 우측 상단 T(문구), 배경, 소리 버튼
- ESC: 열려 있는 설정 모달 닫기
- 전체 화면은 브라우저의 F11 키를 사용합니다. 브라우저 보안 정책상 웹페이지가 F11 동작을 직접 실행할 수는 없습니다.
