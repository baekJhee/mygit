# 깜깜이 콘텐츠

HTML, CSS, JavaScript로 만든 수업용 화면 집중 도구입니다.

## 실행
`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행하세요.

## 폴더 구조
- `index.html` : 화면 구조와 설정 팝업
- `css/style.css` : 디자인 및 반응형 스타일
- `js/app.js` : 모드 전환, 문구, 배경, 이미지, 소리, 전체 화면 기능
- `assets/` : 추후 이미지·음원 파일 보관용

## 주요 기능
- 화면 가리기 / 주목 시키기 모드
- 안내 문구 입력 및 적용
- 기본 배경 5종 및 사용자 이미지 추가
- 소리 on/off (Web Audio API로 생성하는 간단한 멜로디)
- F키 전체 화면, ESC 닫기
